# Испытание в Codex — вручную

В Claude Code испытание запускает скрипт (`scripts/trial.py`). В Codex Desktop его делают руками:
два прогона одной задачи в двух папках, потом слепая проверка. Около 30–60 минут.

## Подготовка
1. Две пустые папки рядом с офисом: `испытание-офис` и `испытание-чат`.
2. В `испытание-офис` — копия офиса без `лиды/*.md` (кроме `_шаблон.md`), `письма/`, `ваш-ход.md`
   и с пустым `экран/events.js`. В `испытание-чат` — только `каталог.md`.
3. Модель в окне чата Codex: **GPT-6.1 Sol, «Среднее»** — одна и та же для обоих прогонов.
4. Запишите, сколько процентов 5-часового окна уже израсходовано (настройки → использование).

## Прогон А — один чат
Откройте `испытание-чат`, новый чат, отправьте:
```
В каталог.md — кто мы, зачем работаем и что предлагаем. Сделай ту же работу одним чатом для 5 объектов: найди их, проверь по их сайтам, результат по каждому — файл письма/<имя>.md. Ничего никуда не отправляй.
```
Запишите: время начала и конца, процент окна после.

## Прогон Б — офис
Откройте `испытание-офис`, новый чат. Если появится окно «Проверка хуков» — «Разрешить все».
Отправьте:
```
Знакомство пропусти. Работаем по каталогу. Найди 5. Запускай сразу, ничего не спрашивай.
```
Запишите то же: время и процент окна. Ещё одно: откройте любого сотрудника в списке справа и
посмотрите, на какой модели он работает — должна быть `gpt-6.1-sol`. Если там модель главного
чата или другая — запишите (в Codex Desktop был такой баг).

## Слепая проверка
Новый чат в папке **над** обеими (чтобы видеть обе), отправьте:
```
Ты — независимый проверяющий. Ничего не меняй и не отправляй. Прочитай каталог.md в любой из папок. Для каждого файла в испытание-чат/письма/ и испытание-офис/письма/ выпиши до 3 главных утверждений о компании, открой ссылки и проверь. Вердикт на файл: «как есть», «правка» или «не отправлять». В конце по каждой папке: как есть / правка / не отправлять / неверных фактов.
```

## Вердикт
Офис готов, если неверных фактов 0 и большинство результатов «как есть». Один чат не хуже —
для этой задачи команда может быть не нужна. Сравнивайте расход окна на один результат «как есть».
