# Модели офиса — что стоит и почему

Правило одно: **модель меняем только по испытанию** (`scripts/trial.py`). Дешевле — лишь если
результатов «как есть» не меньше, а неверных фактов не больше. Экономия, которая портит письма,
дороже: каждое плохое письмо — потерянный адресат.

## Claude Code — все роли на Sonnet 5.5, уровень рассуждения по умолчанию
Замер 25.10.2026 на примере из каталога, 5 компаний, слепая проверка по живым страницам:

| Вариант | Как есть | Неверных фактов | $ | $ за письмо «как есть» |
|---|---|---|---|---|
| Один чат без офиса | 2 из 5 | 3 | 0,61 | 0,31 |
| **Офис, все на Sonnet** | **5 из 5** | **0** | 1,81 | **0,36** |
| Офис, Sonnet с пониженным уровнем | 4 из 5 | 0 | 1,70 | 0,43 |
| Офис, Менеджер и Проверяющий на Opus 5.5 (low) | 3 из 5 | 0 | 2,31 | 0,77 |

- Разведчик на Haiku не находил сайты компаний — офис вставал. Haiku — только для механической
  работы без поиска в сети.
- Больше всего тратят Босс (много ходов) и Разведчик, а не Менеджеры.
- Цены API за 1 млн токенов: Sonnet 5.5 — $2 вход, $10 выход, $0,20 чтение кэша; Opus 5.5 —
  $4 / $20 / $0,20; Haiku 5.5 — $0,10 / $0,50. На подписке это расход лимита, а не деньги.

В файле роли: `claude_model: sonnet`; `claude_effort` не ставим (уровень по умолчанию).

## Codex — все роли на GPT-6.1 Sol, уровень `medium`
- GPT-6.1 Sol (`gpt-6.1-sol`): $2 вход, $10 выход, $0,10 чтение кэша; уровень по умолчанию `medium`. В 2–3 раза дешевле
  моделей 5.x за счёт цены, токенов тратит не меньше.
- GPT-6 Luna (`gpt-6-luna`) расходует лимит примерно в 20 раз медленнее, но чаще выдумывает.
  Разведчиком — только после испытания: на Haiku такая экономия у нас провалилась.
- Модель главного чата (Босса) Codex Desktop берёт из окна выбора: GPT-6.1 Sol, «Среднее».
- В файле роли: `codex_model: gpt-6.1-sol`, `codex_effort: medium`.
- Замер в Codex — по `docs/испытание-codex.md`.
