# Мой офис v0.1.0

Команда ИИ-агентов, которая ищет вам клиентов. Вы говорите с одним Боссом, он раздаёт работу
трём сотрудникам: Разведчик находит компании, Аудитор показывает, где они теряют клиентов,
Менеджер пишет письмо. Вы читаете, одобряете и отправляете сами. На экране «Мой офис» видно, как
человечки-сотрудники получают задания, работают и сдают результат.

Работает в **Claude Code** и в **Codex**, на **Windows** и **Mac**, на подписках от $20
(Claude Pro, ChatGPT Plus).

## Пример
Вы: «Найди 1 компанию». Через 5–10 минут (название вымышлено, находка — типичная):

> **Przykład Dent, Варшава** — кнопка «Umów wizytę» на главной ведёт на страницу контактов без
> формы: записаться можно только звонком в часы работы. Письмо готово: история пациента, который
> в субботу не смог записаться, факты, которые клиника проверит со своего телефона за минуту,
> услуга «Ремонт записи с сайта», 1 500 PLN, перевод для вас и подарок — готовый текст для кнопки
> записи, который клиника может взять бесплатно.

## Почему команда, а не один чат
В обычном чате вы пишете «найди клиентов и напиши им письма» — и одна модель в одной переписке
делает всё подряд. В «Моём офисе»:

| | Один чат | Мой офис |
|---|---|---|
| Кто проверяет | никто: ошибку поиска некому поймать | Аудитор заново открывает сайт и поправляет Разведчика |
| Факты | смешаны с догадками | факт — со ссылкой, гипотеза — словом «вероятно», цена — только из вашего каталога |
| Скорость | по очереди | независимые задачи идут одновременно — видно на экране |
| Расход | сильная модель на всё, переписка растёт | быстрые модели на простое, сильная — только на проверку |
| Память | закрыли чат — всё пропало | каждая компания — файл со статусом; завтра офис продолжит с того же места |
| Решения | агент может «сделать сам» | отправляете только вы; у сотрудников нет инструмента отправки |

## Возможности
- Знакомство: Босс задаёт три вопроса и настраивает офис под ваше дело — что продаёте, кому, в
  каком городе. Или работаете на готовом примере.
- **Вы — заказчик:** перед каждой партией Босс показывает план (сколько компаний, районы, сколько
  кандидатов смотреть, какие признаки искать) и ждёт «да». По ходу — «только Мокотув»,
  «пропусти X», «перепиши письмо X короче».
- **Тайный клиент:** Аудитор проходит путь вашего будущего клиента — поиск, карточка, сайт,
  попытка записаться — и показывает, где тот уходит.
- **Соседи:** сравнение с двумя ближайшими конкурентами.
- **Письмо с подарком:** на языке страны, до 120 слов, с переводом для вас, двумя напоминаниями и
  готовыми ответами на «сколько стоит» и «дорого».
- Ответы клиентов: вставьте ответ — Менеджер подготовит черновик.
- **Пульт:** каждое сообщение Босса кончается строкой «Дальше:» с 1–3 готовыми фразами — отправьте
  любую как есть. «помощь» — меню всех команд: работа, письма, команда, настройки.
- **Команда под вас:** «найми …» — Босс задаст до трёх вопросов и покажет карточку с местом новой
  роли в конвейере («Разведчик → Аудитор → Менеджер → [Редактор] → вы»), нанимает после «да».
  «измени <роль>: …», «уволь <роль>», «кто в команде?». После найма — новый чат.
- **Экран «Мой офис»:** человечки за столами — кто чем занят прямо сейчас; конвейер компаний;
  «Ждёт вас» с кнопками-фразами («покажи письмо …», «одобряю …»): щелчок копирует фразу, вставьте
  её в чат Боссу; шпаргалка «Как управлять»; ход работы; цифры. Ссылки ведут на досье и письма,
  которые сотрудники уже записали. Подстраивается под окно: широкое — две колонки, узкое — вкладки.
  Демо без прогона: допишите к адресу `?src=demo-events.js`.

## Установка
1. Создайте **пустую** папку, например `Projects/my-office` в домашнем каталоге. Не на Рабочем
   столе и не в «Загрузках».
2. Откройте её в Claude Code или Codex. Подтвердите доверие папке, если программа спросит.
   Режим: Claude Code — **Auto** (или «Accept edits»); Codex — **Approve for me**.
3. Отправьте:
```text
Установи «Мой офис» в эту папку по инструкции
https://github.com/ilya0013/my-office/blob/main/INSTALL.md
```
4. Когда агент отчитается: откройте `экран/офис.html` двойным щелчком, начните **новый чат** в
   этой папке и напишите Боссу «Привет».

## Как это работает
```
Вы ─ чат ─ Босс ──┬─ Разведчик (быстрая модель)   → лиды/<компания>.md   статус: новый
                  ├─ Аудитор ×N (сильная модель)  → тот же файл          статус: разобран
                  └─ Менеджер (быстрая модель)    → письма/<компания>.md статус: письмо готово
хуки программы → экран/events.js → экран/офис.html (перечитывает раз в 2 секунды)
```
- `ПРАВИЛА.md` — общие правила; `каталог.md` — ваши услуги, цены и признаки, которые ищет Аудитор;
  `роли/*.md` — инструкции сотрудников.
- `scripts/build_agents.py` собирает из `роли/` агентов для обеих программ:
  `.claude/agents/*.md` и `.codex/agents/*.toml`.
- Сотрудник возвращает Боссу 5 строк, полный результат — в файле. Так Босс, главный расход,
  остаётся коротким.

## Ограничения
- Сотрудники открывают только публичные страницы. Карты Google часто недоступны напрямую — тогда
  в досье честно стоит «не проверено».
- Расход: одна компания — около 5 % пятичасового лимита ChatGPT Plus (замер 25.10.2026).
  Для Claude Pro замер не сделан.
- Письма вы отправляете сами. Как и кому писать — ваше решение.
- В Codex нельзя запретить сотрудникам терминал: ограничение действует как правило в инструкции.
  Терминалу Codex закрыта сеть (`.codex/config.toml`); сайты сотрудники открывают встроенным
  поиском Codex. Claude Code не даёт агентам офиса читать `.env`, ключи и `credentials*`.
- В режиме «на примере» письма подписаны вымышленным человеком из `каталог.md`. Перед отправкой
  настоящей компании замените подпись: «настрой заново» или правка раздела «Обо мне».
- `экран/events.js` растёт с каждым действием. Стал экран медленным — удалите файл, офис начнёт
  показ заново (компании и письма в папках не пропадут).
- Проверено живьём 25.10.2026 на Windows: Claude Code (полный прогон, хуки через Git Bash) и Codex
  (роли и прогон до хуков экрана). Не проверены: Mac целиком, хуки Codex и вариант Claude Code
  без Git Bash.
