# Установка «Мой офис» v0.3.3

Для агента, который ставит офис по ссылке. Владельцу читать не обязательно.

1. Папка должна быть пустой или содержать только служебные файлы программы. Есть чужие файлы —
   ничего не перезаписывай, покажи совпадения и спроси.
2. **Python — вместе с офисом.** Он нужен экрану на Mac, сборке своих сотрудников и откату команды.
   Проверь: Windows — `python -c "import sys; print(sys.version)"` (заглушка Магазина Microsoft
   пишет «Python was not found» — значит, Python нет); Mac — `python3 --version`. Есть Python 3.9 и новее — дальше.
   - **Codex на Windows:** песочница Codex не запускает Python и `winget` из папки пользователя
     («не распознается», «Отказано в доступе»), даже если они стоят. Поэтому в Codex на Windows проверку
     Python, `winget` и все команды `python` офиса (и проверку полным путём) сразу запускай с запросом запуска вне песочницы
     (владелец нажмёт «Разрешить»). Ставить Python — только если и вне песочницы его нет.
   - **Windows, нет:** `winget install -e --id Python.Python.3.12 --scope user --silent
     --accept-package-agreements --accept-source-agreements` (без прав администратора; программа может
     спросить разрешение на установку — это ожидаемо, попроси владельца разрешить). Нет `winget`
     или он упал — скажи владельцу: «Поставьте Python с python.org/downloads, галочка „Add python.exe
     to PATH“» и жди его «готово». Проверь полным путём (папка `Python312`, с python.org — может быть
     `Python313` и новее): PowerShell — `& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" --version`,
     Git Bash — `"$LOCALAPPDATA/Programs/Python/Python312/python.exe" --version`.
   - **Mac, нет** (или `python3` предлагает установку): `xcode-select --install` и скажи владельцу:
     «Откроется окно Apple „Установить инструменты разработчика“ — нажмите „Установить“, это 5–10
     минут; напишите „готово“». После «готово» проверь `python3 --version`. Инструменты уже стоят, а
     Python старше 3.9 — скажи: «Системные настройки → Основные → Обновление ПО, поставьте „Command Line
     Tools“» и после «готово» проверь снова.
   Python поставлен сейчас — в отчёте (последний шаг) первой строкой: «Закройте программу полностью
   (есть значок у часов — правый щелчок → Выйти) и откройте снова — так она увидит Python».
3. Скачай `https://github.com/ilya0013/my-office/releases/latest/download/my-office.zip` во
   временную папку и распакуй. Mac: `tar -xf my-office.zip`. Windows — всегда полным путём, и в PowerShell тоже:
   там `tar` часто ведёт к `tar` из Git, а он zip не читает: PowerShell — `& "$env:SYSTEMROOT\System32\tar.exe" -xf my-office.zip`,
   Git Bash — `"$SYSTEMROOT/System32/tar.exe" -xf my-office.zip`. `unzip` портит русские имена. Перенеси **содержимое** папки `my-office` сюда, включая файлы
   с точкой (`.claude`, `.codex`, `.gitattributes`, `.gitignore`). В bash/zsh: `cp -R <папка>/. .`;
   в PowerShell: `Copy-Item <папка>\* . -Recurse -Force` и отдельно `<папка>\.*`.
   **Копирование заблокировано** (режим Auto проверяет запись в `.claude/`): не повторяй и не предлагай
   владельцу варианты настройки. Одной строкой попроси отправить в чат: «Разрешаю скопировать файлы
   „Моего офиса“ из временной папки в эту папку, включая .claude и .codex» — и после неё повтори копирование один раз.
   Снова заблокировано — скажи: «Переключите режим под полем ввода на „Ask permissions“ и напишите
   „продолжай“ — я спрошу разрешение кнопкой; после установки верните Auto».
4. Проверь, что на месте: `CLAUDE.md`, `AGENTS.md`, `ПРАВИЛА.md`, `каталог.md`, `ваш-ход.md`,
   `роли/` (5 файлов: `управляющий.md`, `скаут.md`, `аналитик.md`, `проверяющий.md`, `_шаблон-роли.md`),
   `.claude/agents/` и `.codex/agents/` (по 3 файла: scout, analyst, checker), `.claude/settings.json`, `.codex/hooks.json`,
   `hooks/office.sh` и `hooks/office.ps1`, `экран/офис.html`, `лиды/_шаблон.md`. Русские имена файлов должны читаться — если видишь
   «╨Я╨а…», распакуй заново другим способом (PowerShell `Expand-Archive`, на Mac `ditto -x -k`).
5. Создай пустой файл `экран/events.js` своим инструментом записи файлов (не `>` и не `Out-File`
   в PowerShell: они пишут UTF-16, и экран его не прочтёт). В него хуки пишут события для экрана.
   **Codex:** хуки проекта он запускает только после разрешения владельца — скажи: «Наберите в
   Codex `/hooks` и разрешите хуки офиса, иначе экран останется пустым».
6. **Только Claude Code на Windows без Git Bash** (у тебя нет инструмента Bash, только PowerShell):
   в `.claude/settings.json` в каждом из шести хуков (`UserPromptSubmit`, `PreToolUse`,
   `PermissionRequest`, `SubagentStart`, `SubagentStop`, `Stop`) замени два поля, символ в символ:
   ```json
   "shell": "powershell",
   "command": "powershell -NoProfile -ExecutionPolicy Bypass -File \"$env:CLAUDE_PROJECT_DIR\\hooks\\office.ps1\""
   ```
   После правки проверь, что файл читается как JSON. Иначе экран останется пустым, а при битом
   JSON пропадут и разрешения на поиск.
7. Временные файлы удали. Глобальные настройки программы не меняй.
8. Отчёт владельцу — коротко, по строкам:
   - «Офис установлен.»
   - «Начните новый чат и напишите „Привет“ — Управляющий откроет экран офиса: в Claude Code — во встроенном
     браузере справа от чата, в Codex даст ссылку. Можно и самому: `экран/офис.html` двойным щелчком.»
   - Ставил Python — «Закройте программу полностью (есть значок у часов — правый щелчок → Выйти) и
     откройте снова — так она увидит Python.»
   - «Начните **новый чат** в этой папке — сотрудники подключаются при старте чата.»
   - Codex: «В новом чате Codex покажет окно „Проверка хуков" — нажмите „Разрешить все",
     без этого экран не видит сотрудников.»
